    AI agent evaluation is the process of measuring how well an
    autonomous, multi-step AI system reasons, uses tools, and completes
    tasks. Unlike testing a single prompt response, it tracks the entire
    path like correct answer, use the right tools, follow the right workflow,
    respond fast enough, and behave safely and reliably

    A good AI agent is not just an agent that gives the correct answer.
    It should give the correct answer, use the right tools, follow the right workflow,
    respond fast enough, and behave safely and reliably.




# EVALUATION CRITERIA


1. Answer correctness
2. Right tool selection
3. Trajectory => did it use the tools in correct order
4. Latency => did it finish within our time limit
5. Safety and Reliability => did it avoid secrets, wrong tool and hallucinations
