# LANGSMITH



LangSmith is a debugging, monitoring, and evaluation platform for applications built
with LLMs and AI agents. It is made by the LangChain team, but it can
also work with applications that do not use LangChain.



LangSmith records this complete execution as a trace, allowing you to inspect every step,
including inputs, outputs, errors, execution time, token usage, tool calls, and model behavior.

For your LangGraph Agentic chatbot, LangSmith can help you:

&Find why an agent selected the wrong tool.
&Inspect the exact prompt sent to the model.
& Debug failed nodes in the LangGraph workflow.
& Measure response latency and token costs.
Review conversations and multi-turn threads.
Compare different prompts or model versions.
Evaluate chatbot quality before and after deployment.
